# ⚖️ 설탕 장수 지훈이의 설탕 배달

> **등식의 성질을 직관적으로 탐구하는 초등·중등 수학 교육용 웹 게임**  
> 양쪽 어깨의 균형을 유지하면서 미지의 설탕 포대($x\text{ kg}$) 무게를 구해보세요!

---

## 🎮 게임 소개

지훈이는 마을 사람들에게 설탕을 배달하는 설탕 장수입니다.  
어깨 지게에 양쪽 균형이 맞도록 짐을 꾸렸지만, **설탕 포대($x\text{ kg}$)**의 무게를 알 수 없어 곤란해졌습니다.  
등식의 성질 4가지 규칙을 활용하여 포대 1개의 무게를 빠르게 알아내 주세요!

### 📌 4가지 핵심 규칙 (등식의 성질)
1. **[규칙 1]** 양쪽에서 동일한 무게의 설탕을 제거할 수 있다. ($A = B \implies A - c = B - c$)
2. **[규칙 2]** 양쪽에 동일한 무게의 설탕을 추가할 수 있다. ($A = B \implies A + c = B + c$)
3. **[규칙 3]** 양쪽의 균형이 깨지면 해당 조작은 무효다. (불균형 시 이전 상태로 복구)
4. **[규칙 4]** 양쪽의 동일한 비율의 설탕을 덜거나 추가할 수 있다. ($A = B \implies A \div c = B \div c$)

## 🚀 주요 기능

1. **자동 방정식 출제 ($ax + b = cx + d$)**
   - 기초 (30초 타임어택)
   - 표준 (40초 타임어택)
   - 심화 (60초 타임어택)
2. **스테이지 5문제 챌린지 & 점수제 순위 시스템**
   - 각 난이도(기초/표준/심화)별로 **총 5문제** 연속 배달 진행
   - **기본 점수**: 문제를 맞히면 **기본 100점** 부여
   - **스피드 점수**: 풀이 시간이 짧을수록 남은 시간에 비례하여 **최대 100점의 스피드 보너스** 추가 부여 (문제당 최대 200점)
   - **오답 감점**: 문제를 틀리면 **현재 점수의 10% 감점**
   - **시간 초과 감점**: 시간 내에 못 풀면 **현재 점수의 30% 감점**
   - **최종 랭킹 산정**: 5문제 완주 후 최종 누적 점수가 높을수록 상위 랭킹 (동점 시 총 소요 시간 빠른 순)
3. **터치 & 마우스 드래그 앤 드롭**
   - 덜어내기 바구니(쓰레기통)로 드래그하여 제거
   - 중앙 설탕 보급소에서 큼직한 포대·봉지를 드래그하여 추가
4. **실시간 어깨 저울 시각화**
   - 양쪽 무게 차이에 따른 지게 기울기 및 지훈이 표정 애니메이션
5. **자동 채점 및 모범 풀이 과정 비교**
   - 학생이 조작한 단계별 등식 기록과 등식의 성질 표준 풀이 과정을 나란히 비교
6. **학습 기록 자동 저장**
   - 정답 수, 평균 해결 시간, 정확도 및 최근 이력 `localStorage` 보존
7. **🏆 실시간 명예의 전당 랭킹 시스템 (Firebase Firestore DB 연동)**
   - 5문제 스테이지 완주 후 획득 점수로 실시간 랭킹 등록
   - 1위(🥇 금메달), 2위(🥈 은메달), 3위(🥉 동메달) 하이라이트 및 내 기록 강조
   - **무설정 즉시 플레이 지원**: Firebase 연동 전에는 `localStorage` 기반 데모 랭킹으로 바로 작동하며, Firebase 키 입력 시 전 세계 실시간 클라우드 DB로 자동 전환

## 🏆 실시간 온라인 랭킹 (Firebase Firestore) 연동 방법

별도의 서버 구축 없이 Google의 무료 **Firebase Cloud Firestore**를 연동하면 전 세계 모든 학생/사용자가 실시간으로 랭킹을 공유할 수 있습니다.

### 1단계: Firebase 프로젝트 생성 및 웹 앱 등록
1. [Firebase 콘솔](https://console.firebase.google.com/)에 접속하여 Google 계정으로 로그인합니다.
2. **[프로젝트 만들기]**를 클릭하고 프로젝트 이름(예: `sugar-balance-game`)을 입력하여 생성합니다.
3. 프로젝트 개요 화면에서 **웹 아이콘 `</>`**을 클릭하여 웹 앱을 등록합니다.
4. 화면에 나타나는 `firebaseConfig` 객체 코드를 복사합니다.

### 2단계: Firestore Database 생성 및 보안 규칙 설정
1. Firebase 콘솔 좌측 메뉴에서 **빌드 ➔ Firestore Database**를 선택하고 **데이터베이스 만들기**를 클릭합니다.
2. 위치는 가까운 리전(예: `asia-northeast3` 서울)을 선택합니다.
3. 데이터베이스 생성 후 상단의 **규칙(Rules)** 탭으로 이동하여 기존 내용을 모두 지우고 아래 코드를 그대로 붙여넣은 뒤 **[게시]**(또는 Publish)를 누릅니다:
   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /leaderboard/{docId} {
         // 누구나 설탕 배달 랭킹을 조회하고 등록할 수 있도록 허용
         allow read, write: if true;
       }
     }
   }
   ```
   *(또는 간편하게 `match /{document=**} { allow read, write: if true; }` 로 설정하셔도 됩니다.)*

### 3단계: `firebase-config.js`에 설정 붙여넣기
프로젝트 루트 폴더의 `firebase-config.js` 상단 `firebaseConfig` 객체에 1단계에서 복사한 값을 입력합니다:
```javascript
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "sugar-game-xxxx.firebaseapp.com",
  projectId: "sugar-game-xxxx",
  storageBucket: "sugar-game-xxxx.appspot.com",
  messagingSenderId: "123456789...",
  appId: "1:123456789:web:xxxx"
};
```
저장 후 배포(또는 브라우저 새로고침)하면 상단 랭킹창의 상태 뱃지가 `🟢 온라인 실시간 DB 연동됨`으로 바뀌며 온라인 랭킹이 활성화됩니다!

*(※ 키를 입력하지 않아도 `🟡 로컬/데모 모드`로 브라우저 내에서 즉시 랭킹 등록과 테스트가 가능합니다.)*

## 🌐 GitHub Pages 배포 설정 방법

1. GitHub 저장소의 **Settings** ➔ **Pages**로 이동합니다.
2. **Build and deployment** ➔ **Source**를 `Deploy from a branch`로 설정합니다.
3. **Branch**를 `main` / `/ (root)`로 선택하고 **Save**를 클릭합니다.
4. 1~2분 후 생성되는 `https://<사용자명>.github.io/<저장소명>/` 링크로 접속하면 누구나 바로 게임을 플레이할 수 있습니다!
